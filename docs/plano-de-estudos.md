## 3. Projeto prático — TechPulse

O TechPulse será utilizado como ambiente de aplicação dos conhecimentos adquiridos.

### Escopo inicial do MVP

1. Coletar notícias de algumas fontes RSS.
2. Identificar e remover notícias duplicadas.
3. Classificar notícias com auxílio do Gemini.
4. Gerar resumos automáticos.
5. Armazenar os resultados.
6. Disponibilizar uma demonstração do fluxo.

Funcionalidades adicionais, como dashboard completo, personalização e newsletter, serão consideradas somente se o núcleo estiver funcionando.
